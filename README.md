# Site_pessoal

## Secoes do Site

### 1. Hero Section
- Titulo principal com efeito gradiente animado
- Subtitulo com apresentacao profissional
- Botoes de navegacao para projetos e contato

### 2. Sobre Mim
- Cards com estatisticas (projetos, linguagens, redes, paixao por aprender)
- Design com efeito hover e animacoes

### 3. Projetos e Interesses
- Card principal destacado para Desenvolvimento Full Stack
- Cards para: Games, Musica, Conteudo Digital, Edicao
- Tags para tecnologias e habilidades

### 4. Contato
- Botoes de acao rapida:
  - WhatsApp (link direto para conversa)
  - E-mail (link com assunto pre-preenchido)
- Exibicao do e-mail
- Links para redes sociais (GitHub, LinkedIn, Instagram, YouTube)

---

## Funcionalidades Implementadas

### Front-end Interativo
- Barra de Progresso: Indica o progresso da rolagem da pagina
- Scroll Reveal: Elementos aparecem com animacao suave ao rolar
- Navegacao Suave: Clique no menu com scroll animado
- Menu Fixo: Navegacao sempre visivel com efeito glassmorphism
- Hover Effects: Feedback visual em todos os elementos interativos

### Performance e Acessibilidade
- Otimizado para SEO: Meta tags e estrutura semantica
- Responsivo: Adaptacao para todos os tamanhos de tela
- Acessivel: Atributos ARIA e contraste adequado
- Carregamento rapido: Sem dependencias pesadas
